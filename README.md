# My Little Budget

## 목적

AI를 활용해 사용자의 소비 흐름을 정리하고, 예산 관리를 돕고, 일상적인 지출 맥락에서 경제 개념을 쉽게 이해할 수 있도록 돕는 Flutter 기반 애플리케이션입니다.

## 기술 스택

| 구분 | 기술 | 목적 |
| --- | --- | --- |
| 앱 | Flutter | 모바일 앱 UI와 사용자 경험 구현 |
| 앱 | Dart | Flutter 앱 개발 |
| 백엔드 | NestJS | API 서버 구현 |
| 언어 | TypeScript | NestJS 백엔드 개발 |
| 데이터베이스 | PostgreSQL | 거래내역, 예산, 카테고리 등 관계형 데이터 저장 |
| ORM | Prisma | 데이터베이스 접근과 마이그레이션 관리 |
| 앱 인프라 | Firebase | 인증, 푸시 알림, 앱 분석 등 모바일 기반 기능 |
| 클라우드 | GCP | Firebase와 AI 기능을 포함한 초기 클라우드 기반 |
